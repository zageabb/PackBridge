## Alternative Virtual SSD review concepts

The `04B` set explores an SSD-document-style review workflow with case-by-case editing, source traceability, field provenance, correction, and inline validation. These designs are alternatives to the grid-first `04 — Virtual SSD Workspace` and are provided for comparison before the preferred implementation is selected.

This frame is editable directly in the Figma source file and shows the main SSD-style case review workspace.
